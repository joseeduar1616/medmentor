Histórico de consultas

Inteligência artificial (Claude)

Com uma chave da API da Anthropic o Scribe usa IA para organizar a transcrição no modelo. Sem chave, funciona no modo offline (distribui as frases por palavras‑chave — bem menos preciso). A chave fica salva só neste navegador.

⚠️ Privacidade (LGPD)

Tudo é salvo apenas no seu navegador (localStorage). Ao usar a IA, a transcrição é enviada à API da Anthropic. Evite nomes completos, CPF, endereço e outros identificadores — use iniciais. O texto gerado é um rascunho: a responsabilidade pelo registro é do médico.
